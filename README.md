## 🚀 How to Deploy to GitHub & GitHub Pages

This project is built using modern standards (HTML5, CSS3, ES6 JavaScript) and CDN-delivered libraries. **No complex build steps or node modules required.** You can deploy it to GitHub Pages in under 2 minutes:

### Option 1: Using Git Command Line

1. Initialize git and commit:
   ```bash
   cd yash-properties-3d
   git init
   git add .
   git commit -m "feat: initial commit of Yash Properties 3D luxury platform"
   ```

2. Create a new repository on [GitHub](https://github.com/new) called `yash-properties-3d`.

3. Push to your repository:
   ```bash
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/yash-properties-3d.git
   git push -u origin main
   ```

4. Enable GitHub Pages:
   - Go to your repository **Settings** &rarr; **Pages** (on the left sidebar).
   - Under **Build and deployment > Source**, select **Deploy from a branch**.
   - Under **Branch**, select `main` and `/ (root)`, then click **Save**.
   - Your website will be live in ~60 seconds at `https://YOUR_USERNAME.github.io/yash-properties-3d/`!

---

### Option 2: Drag & Drop via GitHub Web UI

1. Create a new repository on [GitHub.com](https://github.com/new) named `yash-properties-3d`.
2. Click **"uploading an existing file"**.
3. Drag the files from this directory (`index.html`, `css/`, `js/`, `assets/`, `README.md`) into the GitHub upload area.
4. Click **Commit changes**.
5. Go to **Settings &rarr; Pages**, choose `main` branch, and save!
